# SENTIR · Coordinadora de convivencia

Proyecto frontend responsive con las pantallas:
- Inicio
- Casos reportados
- Alertas
- Seguimiento
- Convivencia
- Reportes
- Mi perfil

## Cómo abrir
1. Extrae el ZIP.
2. Abre la carpeta completa en Visual Studio Code.
3. Abre `index.html` con Live Server.

## Funcionalidad incluida
- Navegación entre todas las pantallas.
- Sidebar responsive con menú hamburguesa.
- Alertas con filtros, revisión y conversión a caso.
- Casos con filtros, registro de caso, detalle y cambio de estado.
- Seguimiento con notas y cambio de etapa.
- Convivencia con actividades, mediaciones y compromisos.
- Reportes con gráficos, impresión y exportación CSV.
- Perfil con cambio de foto y datos.
- Persistencia de datos de demostración mediante `localStorage`.

## Nota
Este ZIP es un frontend funcional de demostración. No incluye conexión a PHP/MySQL ni autenticación real. Los datos se guardan localmente en el navegador para que todas las pantallas estén entrelazadas durante la prueba.
