# SENTIR · Coordinadora de convivencia — gestión completa

Esta versión conserva el mismo diseño visual y responsive del panel anterior,
pero corresponde a una segunda coordinadora con permisos ampliados.

## Pantallas incluidas
- Inicio
- Casos reportados
- Alertas
- Seguimiento
- Convivencia
- Reportes
- Mi perfil

## Funciones adicionales de esta versión
### Alertas
- Crear nuevas alertas.
- Editar alertas existentes.
- Filtrar y buscar alertas.
- Marcar alertas como revisadas.
- Convertir una alerta en caso.

### Convivencia
- Crear, editar y eliminar actividades.
- Crear, editar y eliminar compromisos.
- Marcar compromisos como completados.
- Registrar, editar y eliminar mediaciones.
- Los cambios quedan guardados en `localStorage`.

## Otras funciones
- Gestión de casos y cambio de estados.
- Notas de seguimiento.
- Reportes, gráficos e impresión.
- Exportación CSV.
- Cambio de foto y datos del perfil.
- Sidebar responsive y menú hamburguesa en tablet/celular.

## Cómo abrir
1. Extrae el ZIP completo.
2. Abre la carpeta en Visual Studio Code.
3. Abre `index.html` con Live Server.

## Importante
Esta entrega es un frontend funcional de demostración. Los datos se guardan
en el navegador mediante `localStorage`; todavía no está conectada a PHP/MySQL.
